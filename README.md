# 🌍 ГеоМастер

Интерактивная карта мира с викторинами на знание стран.

## Разработка

```bash
npm install
npm run dev        # http://localhost:3000
```

## Сборка одного файла

```bash
npm run build      # создаст dist/geomaster.html
npm run preview    # предпросмотр собранного файла
```

## Структура

- `src/config.js` — все константы (легко менять уровни, время вопроса)
- `src/data.js` — база стран и фактов (добавляйте новые страны сюда)
- `src/core.js` — состояние, storage, звуки, темы, статистика
- `src/ui.js` — тосты, модалки, частицы
- `src/map.js` — D3-карта (плоская и глобус)
- `src/quiz.js` — логика викторины
- `src/screens.js` — все экраны (панели)
- `src/main.js` — точка входа, роутинг режимов

## Как добавить страну

1. Откройте `src/data.js`
2. Добавьте в нужный континент: `"XXX": ["Название", "Столица", "flag_code"]`
3. По желанию — добавьте факты в `COUNTRY_FACTS`
4. `npm run build`

## Как добавить ачивку

1. Откройте `src/data.js`, массив `ACHIEVEMENTS`
2. Добавьте объект: `{ id, icon, name, desc, progress, check }`
3. Готово — `checkAchievements()` подхватит автоматически
