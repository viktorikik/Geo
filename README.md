# 🌍 ГеоМастер

Интерактивная карта мира с викторинами на знание стран, столиц и флагов.  
Чистые ES-модули, без сборщиков и npm-зависимостей в рантайме. Работает на GitHub Pages.

## Демо

Откройте `index.html` через любой статичный сервер (см. ниже) или опубликуйте на GitHub Pages.

## 🚀 Запуск локально

```bash
npx serve .
# или
python3 -m http.server 3000
